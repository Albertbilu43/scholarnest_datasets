

1 Understanding Big Data and Distributted Data Processing

1.1 INTRODUCTION TO COURSE

Hadoop 
Is a way to distribute very large files across multiple machines. It uses Hadoop Distributed File System(HDFS).
HDFS allows a user to work with large data sets
HDFS uses MapReduce, which allows computations on that distributed data.
MapReduce is a way of splitting a computation task to a distributed set of files(such as HDFS)

So we use:
-HDFS to distribute large data sets
-MapReduce to distribute a computational task to a distributed data set.

Spark vs MapReduce
-MapReduce requires files to be stored in HDFS, Spark DOES NOT
-Spark can perform up to 100x faster than MapReduce
-Spark can spill over to disk if the memory is filled
-At the core of Spark is Resilient Distributed Dataset(RDD)
-RDD has 4 main features:
 *Distributed Collection of Data
 *Fault-tolerant
 *Parallel operation-partitioned
 *Ability to use many data sources
-RDDs are immutable
-Two types: 
  Transformations: Are the recipe to follow
  Actions:         Perform what the recipe says to do and return sth. back.

RDD vs Dataframe
-Spark 2.0 moved from RDD to Dataframes
